# Anchor

A caregiver-patient pairing app built with React Native and Expo.

## Getting Started

```bash
npm install
npx expo start
```

## Setup

1. Create a `.env` file with your Supabase credentials:

```
SUPABASE_URL=your_url
SUPABASE_ANON_KEY=your_key
```

2. Run the SQL in `lib/schema.sql` in your Supabase SQL Editor.

3. Scan the QR code with Expo Go to launch the app.
